# 过程材料与交接件清退

仅在本任务产生或实际使用了过程材料、临时文件或交接件时读取；没有这类材料时不扫描目录凑候选。

## 脚手架清退（过程 / 交接文档的退役）

用户发起交互收尾时，检查本任务产生或实际使用的过程材料和交接件，包括临时文件、一次性脚本、预览稿，以及父任务或其他任务提供的同类文件。共享正本、业务原始资料和正式成果，不因被本任务使用过就自动纳入清理。

按文件所属项目规则、当前实际职责、已知后续需求和必要保留责任判断，不按文件名、日期或 `type: 脚手架` 标记直接决定删除。仍有用的内容，在已有授权内按原有性质承接到现有适当位置，保留必要证据；未完成承接的保留原件。未决建议不得借承接变成已批准规则。

确认已无独有有效信息、未处理的现行引用、后续依赖或必要追溯、验收、恢复用途后，仅在当前用户已有授权明确覆盖对象、范围和影响，且适用项目规则允许时删除；同批授权不重复确认，无授权则先提交具体清理范围。是否需要备份或可恢复删除遵循用户与项目约定，本 Skill 本身不授予删除权限。历史记录中的单纯提及，不单独构成保留理由；归属、依赖或保留价值判断不清的先保留，并说明关键缺口。

删除前核对最新状态，删除后确认目标已清理、保留成果与现行引用完整，并简短报告清理结果。交互收尾授权不自动扩展到自动化；自动化按[自动化复盘分支](automation-review.md)的既有授权边界执行。
